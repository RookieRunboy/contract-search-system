# Proposal: 重构搜索筛选器交互 (Redesign Search Filters)

## Goal
将当前 `SearchPage` 中基于折叠面板（Collapse/Form）的"高级筛选"功能，重构为 **英特尔风格的纵向筛选器列表**设计。
每一行是一个独立的筛选条件，包含两个下拉框：第一个选择筛选类型，第二个选择筛选值，右侧有删除按钮。

## Context
目前的"高级筛选"是一个隐藏的表单区域，展开后占用大量垂直空间，且不够直观。
用户希望使用类似英特尔官网的筛选器设计模式，即：

1. **纵向列表布局**：每个筛选条件独占一行，垂直堆叠排列。
2. **双下拉框交互**：每行包含两个下拉框：
   - 第一个下拉框：选择筛选维度/类型（如"签订日期"、"合同金额"、"我方实体"等）
   - 第二个下拉框：选择该维度的具体值（根据类型动态变化，可能是日期选择器、数字输入、单选/多选列表）
3. **便捷删除**：每行右侧有一个"×"按钮，可直接删除该筛选条件。
4. **按需添加**：底部有"选择筛选器"下拉框，点击后可添加新的筛选行。

## Visual Reference
参考英特尔官网的筛选器设计：
- 黑色/深色背景的筛选器行
- 左侧下拉框选择类型（如"ECC 内存支持"）
- 右侧下拉框选择值（如"ECC 内存支持 - 是"）
- 每行右侧有"×"删除按钮
- 底部有空行供添加新筛选器

## Scope
- **前端变更**：`SearchPage.tsx`、新增 `FilterBar.tsx` 组件
- **无后端改动**：复用现有的 `SearchFilters` API 参数接口
