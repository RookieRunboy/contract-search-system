# AI 文本解析与合同筛选条件提取

**Change ID**: ai-text-analysis
**Status**: Proposed

## 目标
实现一个集成在合同检索页面（SearchPage）的 AI 文本解析功能。允许用户输入长文本（如招标文件、需求描述），系统利用大模型（LLM）分析该文本，提取关键信息，并自动填充搜索页面的关键词和高级筛选条件，辅助用户快速进行精准检索。

## 范围
1.  **后端**:
    *   新增 API 接口，接收长文本输入。
    *   集成 LLM（复用现有的 DeepSeek 客户端），提取关键词和筛选条件。
    *   返回结构化的分析结果（Keywords, Filter Conditions）。
2.  **前端**:
    *   **在搜索栏内部嵌入 "✨" AI 触发图标**。
    *   **新增 "智能助手侧边栏" (AI Copilot Drawer)**：
        *   采用**右侧滑出**交互，保留用户上下文。
        *   **UI 升级**: 使用现代化设计语言（如卡片式、微交互动画）。
        *   **动态反馈**: 分析过程展示波纹/加载动画，结果采用流式展示。
        *   **一键应用**: 确认后自动将提取的条件"填入"搜索栏并触发搜索。

## 理由
用户手动从长篇招标文件或需求文档中提炼搜索条件效率较低。将 AI 解析功能直接嵌入搜索流程，形成 "粘贴需求 -> AI 提取 -> 确认条件 -> 自动搜索" 的流畅体验，可以大幅提升用户的工作效率。
