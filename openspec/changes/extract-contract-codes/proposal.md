# Change: 提取合同编码与CIR编码

## Why
用户反馈合同文件命名包含重要的业务信息，具体为“合同编码”和“合同注册编码（CIR编码）”。
目前系统仅存储完整文件名，未解析这两个关键字段，导致用户无法在列表中直观查看或检索这两个编号。
用户提供了四种明确的命名格式，系统需要支持自动解析。

## What Changes
- **后端**：
    - 在文件上传处理逻辑中增加文件名解析步骤。
    - 支持解析四种命名模式：
        1. `[合同编码]-[CIR编码]合同名`
        2. `[合同编码]合同名`
        3. `[CIR编码]合同名`
        4. `合同名` (无编码)
    - 更新内部数据结构（如 metadata）以存储 `Contract Code` 和 `CIR Code`。
    - **区分规则**：
        - **CIR 编码**: 格式为 "CIR" (不区分大小写) 加上数字 (例如 `CIR500000220616010`)。
        - **合同编码**: 格式通常为字母开头加上数字 (例如 `C500000220616005`)。
        - **解析逻辑**：提取括号内的内容，若符合 CIR 格式则识别为 CIR 编码，否则识别为合同编码。
- **前端**：
    - 更新“合同上传”页面的文件列表，新增“合同编码”和“CIR编码”两列。
    - 确保这些字段在上传后能正确显示。

## Impact
- Affected specs: `contract-management`
- Affected code: `backend/contractApi.py`, `frontend/src/pages/UploadPage.tsx`, `frontend/src/types/index.ts`
