# 增强客户分类筛选器 - 提案

## 背景

当前的合同搜索系统的客户分类筛选功能存在以下问题：

1. **一级和二级分类分离**：用户需要添加两个独立的筛选行分别选择一级和二级分类
2. **单选限制**：虽然技术上支持多选，但交互不够直观
3. **二级分类依赖不明确**：二级分类的可用选项依赖于一级分类的选择，但用户需要先添加一级分类筛选行，再添加二级分类筛选行

## 目标

将客户分类筛选改造为一个**统一的层级式选择器**，提供更直观的多选体验：

- **统一选择器**：在同一个筛选行中同时显示一级和二级分类下拉框
- **一级分类多选**：通过新增选择器实现多组一级+二级的筛选
- **二级分类多选**：每个选择器内的二级分类支持多选
- **默认全部二级**：选择一级分类后，二级分类默认为"全部二级分类"
- **级联关系**：二级分类选项自动根据所选一级分类进行过滤

## 变更范围

### 前端变更

1. **创建新组件 `HierarchicalCategoryFilter`**：
   - 单行内包含一级下拉框（单选）和二级下拉框（多选）
   - 一级下拉框选择后，二级选项自动更新
   - 二级下拉框支持多选，默认选中"全部"

2. **修改 FilterRow 类型**：
   - 将 `categoryL1` 和 `categoryL2` 合并为单一类型 `category`
   - 简化筛选器类型列表，移除分开的一级/二级选项

3. **修改 FilterBar 逻辑**：
   - 支持多个 `category` 类型的筛选行（实现一级分类多选）
   - 每个筛选行独立维护一级+二级选择状态
   - 将多行的选择结果合并为 API 参数

### 后端不变

后端 API 已支持 `customer_category_level1` 和 `customer_category_level2` 数组参数，无需修改。

## 用户体验流程

1. 用户点击"选择筛选器"，选择"客户分类"
2. 该筛选行显示两个下拉框：
   - 左侧：一级分类（单选）
   - 右侧：二级分类（多选，默认"全部"）
3. 用户选择一级分类后，右侧二级下拉框选项更新为对应的二级分类
4. 用户可以在二级下拉框中多选具体分类，或保持"全部"
5. 若需要筛选多个一级分类，用户添加新的"客户分类"筛选行
6. 系统自动合并所有一级分类及其对应的二级分类进行搜索

## 影响评估

- **用户体验改进**：减少操作步骤，更直观地选择分类
- **代码复杂度**：中等，需新增一个层级选择组件
- **兼容性**：与现有后端 API 完全兼容
- **回归风险**：低，筛选逻辑核心不变
